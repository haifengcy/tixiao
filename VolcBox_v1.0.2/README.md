你是不是也经常在 Figma 里被迫做这些毫无创造力的“体力活”：

1. 😫 **出海多语言翻译，排版重做一遍**：逐个图层复制去翻译软件，粘回来后粗体没了、颜色变了、字阶全乱，几十个画板要手动改一整天；

3. 😵 **给老板/客户看配色，解组改到崩溃**：想快速看下换套主题色或暗色系效果，几十个组件与嵌套 Frame 必须一层层点进去改 Fill，改完全部乱套；

## ✨ 使用 VolcBox，你能获得什么？（收益清单）

不再需要把精力耗在机械搬砖上，插件能直接为你带来这些切实的提效收益：

- ✅ **节省 90% 出海出图时间**：一键将成百上千个文本图层翻译为全球 100+ 语种。**最关键的是：局部加粗、变色、字号 1:1 像素级原样保留**，无需任何手动格式返工。
- ✅ **1 秒生成真实业务级原型**：告别假数据，一键批量填充欧美/中文高频人名、全球热门城市、真实电商标价与企业邮箱，**同时自动规范化重命名图层**，评审交付逼真专业。
- ✅ **3 秒极速推演整套设计配色**：**无需解组复杂画板**，直接对选中画板调控色相 (Hue)、饱和度与明度，支持只改填充或只改描边，多套视觉方案秒级呈现。
- ✅ **微信 / 飞书 ⌘+V 秒级直发**：内置双模极速直拷，后台静默将多个画板拼合成带标题的高清图并写入操作系统剪贴板，切到聊天窗直接粘贴发送。
- ✅ **节省 70%+ 图片资产存储**：内置 TinyPNG 多 Key 自动轮询调度（轻松突破每月 500 次限制）+ 本地高保真无损离线引擎兜底，导出包又快又小。
- ✅ **换电脑 0 迁移成本**：专属独立密钥端到端加密，所有 API 配置与自定义词库云端秒存秒取，多设备无缝衔接。

## 🚀 极速上手（3 步以内）

1. **下载解压插件包**：
   - 直接下载最新 [VolcBox_v1.0.2.zip](https://volcbox.pages.dev/VolcBox_v1.0.2.zip) 并解压到本地文件夹；
   - 或使用 Git 克隆：
     ```bash
     git clone https://github.com/haifengcy/Figma-VolcBox.git
     ```
2. **在 Figma 中导入**：
   - 打开 Figma 任意文件，点击顶部菜单：`Plugins (插件)` ➔ `Development (开发)` ➔ `Import plugin from manifest...`；
   - 选中解压目录中的 **`manifest.json`**；
3. **即刻开始提效**：
   - 在画布中选中任意画板或图层，随时运行 VolcBox，开启极速提效！

## ⚠️ 限制与兼容性说明

- **运行环境兼容**：完美支持 Figma 桌面客户端（macOS / Windows）及 Web 浏览器端；
- **图层操作范围**：文本翻译与数据填充仅作用于 **`TEXT` 文本图层**，若画板内图层处于「锁定 🔒」状态，请先解锁；
- **剪贴板极速直拷模式**：
  - 🖥️ **桌面端模式**：一键安装内置的极速轻量服务后，拼图直接写入操作系统剪贴板，微信/飞书 ⌘+V 秒发；
  - 🌐 **纯沙箱/网页端模式**：零配置下自动在当前画布中生成带标题的高清排版 Frame，可自由导出或二次调整。
