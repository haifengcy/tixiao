Core Capabilities

聚焦实用，覆盖 6 大高频设计环节

不搞花哨概念，在一个轻量统一的界面中解决日常设计、本地化与团队协同痛点。

🌐 多语言智能翻译

支持全球 100+ 语言；可原地替换文本或一键批量克隆扩展画板；翻译后保留局部加粗、颜色与字号等富文本样式；支持内置通道或接入 DeepSeek / OpenAI 等自定义 Key。

📝 真实数据批量填充

内置常用人名、全球城市、电商价格、企业邮箱等多类高频数据；支持粘贴自定义词库，一键对选中文本进行正序、随机、倒序填充与图层重命名。

🖼️ TinyPNG 多池极速压缩

支持配置多个 TinyPNG API Key 自动轮询使用，突破单 Key 500 次限额；无 Key 时自动切换本地离线引擎；支持自定义导出倍率、格式与文件夹。

🎨 画板全局色彩调节

无需逐个图层解组，直接对选中的画板或图层调节色相、饱和度与明度 (HSL)；支持仅作用于填充或仅作用于描边，快速调整设计方案配色。

🛠️ 设计快捷小工具

支持画布多画板生成带标题的高清拼图、批量导出所选画板、文本行高批量 Auto 与固定像素互转、自动裁切 PNG 图片四周透明留白。

☁️ 跨设备配置云同步

专属同步密钥机制，换电脑或新安装插件后，只需输入密钥一键拉取所有 API Key、TinyPNG 池与词库偏好，免去重复配置的繁琐。

Quick Start

简单 3 步，在 Figma 中开启使用

本地离线加载，安全可靠，开箱即用。

01

下载插件安装包

直接点击上方「下载插件」获取 `VolcBox_v1.0.1.zip`，并解压到本地任意目录。

02

在 Figma 中导入

在 Figma 菜单点击 `Plugins` ➔ `Development` ➔ `Import plugin from manifest...`，选中解压出的 `manifest.json`。

03

即刻开始提效

在 Figma 中随时运行 VolcBox，即可开始多语言翻译、批量数据填充与图片压缩！

FAQ

常见问题解答

本项目完全开源且免费使用。基础多语言翻译通道开箱即用；同时也支持在设置中直接填入你自己的 DeepSeek 或 OpenAI API Key，无任何中间收费。
可在 tinypng.com/developers 免费获取 API Key（每个账号每月赠送 500 张额度）。在 VolcBox 中添加多个 Key 即可自动轮询；若不填 Key，插件会自动使用本地离线无损引擎完成导出。
在插件「设置」页面生成专属同步密钥（例如 `VB-XXXX-XXXX`）。在新电脑安装插件后，输入该密钥并点击「绑定并同步」，所有 API Key、TinyPNG 池与词库偏好将瞬间全部恢复。
